DS Bot 浏览器 / 电脑操作修复工具 1.0

解压后双击“DSBot-Repair.exe”（或“启动修复工具.cmd”），无需安装 Node.js，不需要联网。
请把整个目录保留在一起，不要只复制启动文件。

使用步骤
1. 确认安装目录和数据目录。默认对应当前 Windows 用户。
   数据目录应包含 profiles\ds-bot\cordis.patch.yml 和 bot\state.json。
   如 DS Bot 迁移过数据，请在这里选迁移后的目录。
2. 点击“检测”。它会实际加载浏览器驱动、读取电脑驱动工具目录并调用 list_apps。
   检测不点击、不输入、不读取剪贴板，也不把应用名称写入报告。
3. 保存 DS Bot 中正在进行的工作，勾选要修复的项目，点击“修复并重启”。
   工具会完整结束所选安装目录的 DS Bot 进程，当前任务会停止。
4. 回到 DS Bot 按下方步骤验收。

浏览器修复做什么
- 保留已有的 refs / script / task 选择；未配置时启用 refs。
- 驱动缺失时，从离线包安装 playwright-core 1.65.0 到所选数据目录。
- 设置 playwrightUrl，使 DS Bot 连接自己的浏览器面板。
- 不下载 Chromium；使用 DS Bot 自带的浏览器。
- 完整重启，避免旧会话继续持有过期工具注册状态。

电脑操作修复做什么
- 修复 Cua Driver 0.28.0 在 Electron ASAR 中加载原生 DLL 的路径问题。
  原始加载器可能给 FFI 一个 app.asar 内的虚拟路径，而 DLL 需要真实磁盘路径。
  补丁仅在 app.asar.unpacked 中对应文件确实存在时转换路径。
- 如驱动的解包文件缺失或损坏，只有离线文件的 SHA-256 与安装包记录一致时才恢复。
- 启用电脑操作总开关，保留每个 Bot 的权限等级、应用授权和受保护应用限制。
- 实际创建驱动、读取工具目录并调用 list_apps；不执行鼠标或键盘操作。
- 如某个 Bot 被单独设为“关闭”，工具会保留该选择并在检测结果中提示。

如何验收
浏览器：在目标 Bot 的浏览器面板打开百度，告诉它：
“调用 browser_snapshot，再用 browser_type 在百度搜索 test。”
确认面板显示 test 的搜索结果。
（使用 script / task 插件的用户，使用该插件对应工具操作。）

电脑：告诉目标 Bot：
“列出已打开的应用和窗口，确认电脑操作工具正常。”
如要验证输入，在记事本新建一个空白文档，授权该 Bot 使用记事本，
让它输入 DS Bot computer test，肉眼确认。应用授权仍通过 DS Bot 自己的提示完成。
登录、验证码、付款，以及受保护应用操作，仍遵守 DS Bot 原有规则。

检测通过不等于所有 Bot 的所有应用均已授权；报告不会把原生驱动测试冒充聊天内验收。

备份与回滚
- 每次修改前，在 数据目录\capability-repair\backups\时间戳 保存原始文件和事务清单。
- “回滚并重启”撤销最近一次有实际修改的修复。
- 配置回滚只恢复本工具改动的两个浏览器字段和电脑总开关，保留后来修改的其他设置和聊天。
- 如这些字段或驱动文件在修复后又被其他程序修改，停止回滚并提示冲突，避免覆盖。
- 离线驱动缓存会保留，方便再次修复；回滚后不会主动删除其他文件。
- 失败时自动尝试恢复本次写入前的文件；备份清单也保留中断恢复所需的信息。

适用范围
此版本已验证 Windows x64、DS Bot 0.3.1、Cua Driver 0.28.0。
对不匹配的版本，只检测，不自动套用补丁。
不修改 app.asar，不修改模型、API Key、连接器、聊天内容、Windows 安全设置。
如果安装在需要管理员权限的位置，请在确认目录正确后，以管理员身份运行启动文件。
升级或重装 DS Bot 后，可重新检测；新版不匹配时请使用更新的修复工具。

报告
reports 目录保存检测报告，仅留在本机，不上传。
报告可能包含安装目录、数据目录及驱动加载错误；不包含 API Key、聊天正文和应用列表。
备份留在 DS Bot 数据目录，包含原文件，请像保护 DS Bot 数据一样保护备份。

命令行（可选，有 Node.js 20+ 时）
node repair.mjs detect
node repair.mjs repair --components browser,computer --restart
node repair.mjs rollback --restart
自定义目录：追加 --app-dir "DS Bot 安装目录" --home "DS Bot 数据目录"

第三方组件说明见 THIRD-PARTY-NOTICES.txt；离线包包含对应许可证和通知文件。
